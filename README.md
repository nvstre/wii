# Wii U Menu

A portfolio site styled after the Wii U Menu (GamePad screen). Plain HTML/CSS/JS, no build step.

- Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages works).
- Customize tiles, the bottom shortcuts, and the user icon in `js/config.js`.
- Controls: click/tap a tile to select it, again to open; arrow keys + Enter; swipe, wheel or the side arrows to change pages; Esc closes an open app.

All artwork and sounds are original placeholders. No Nintendo assets are included.
